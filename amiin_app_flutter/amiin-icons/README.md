# Amiin — Icônes de l'application

Pack d'icônes de la marque **Amiin · App Assistance Djibouti**.

## Variantes

- **dark/**    — Fond sombre #1A1208, mark terra #B85530 (variante principale, App Store)
- **terra/**   — Fond terra #B85530, mark blanc (notifications, accents)
- **light/**   — Fond crème #F4EFE6 (mode clair, contextes lumineux)
- **mono/**    — Monochrome blanc sur noir (favicon, barres système)
